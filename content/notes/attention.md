## 1. 什么是 Attention?

简单讲，注意力机制可以理解为一种动态加权聚合机制，它借鉴了数据库中的查询手段，在传统数据库中，查询是离散的精确匹配：通过一个 Query 找到匹配的 Key，返回唯一的 Value。注意力机制借鉴了这种做法，并把原先返回唯一的 Value 改为返回一个不同 Value 的加权聚合值。其基本操作流程为，首先，根据需要查询的信息 Query，计算 Query 与每个 Key 之间的相似度，随后使用归一化函数 Softmax，将相似度转换为和为 1 的概率分布，最后使用该概率分布与 Value 进行加权聚合，得到最终的查询输出。具体公式即：

$
attention = \operatorname{softmax}\left(\frac{QK^\top}{s\sqrt{d_k}}+M\right)V
$

从公式上理解，可以简单理解为 $QK^\top$ 表示逐点的相似度，类似没有除以模长的余弦相似度，随后，除以 $\sqrt{d_k}$，目的是防止点积随着向量维度增大而变得过大，从而让 Softmax 保持稳定。$M$ 作为掩码，在因果生成和时序生成中可以进行设计，最后将输出做 Softmax，并和 Value 加权，获得最终解。

## 2. 怎么理解 Attention?

简单的讲，Attention 可以理解为对信息的相关性做检索，然后进行整合，如果更一般的说，注意力是一个由输入动态生成的矩阵，通过输入动态生成 ${softmax}\left(\frac{QK^\top}{s\sqrt{d_k}}+M\right)$，随后对 Value 进行聚合检索。事实上，$Q$ $K$ $V$ 三个量可以来自不同的数据，这在后面的 Cross Attention 里可以具体体现。

## 3. Cross Attention

如果将 $Q$ $K$ $V$ 改为来自不同的数据，则可以描述不同数据序列之间的相关性。Cross Attention 就是这么做的，它的 $Q$ 来自于一个数据序列，而 $K$ $V$ 则来自另一个数据序列，此时，注意力机制即在两个数据序列之间展开，通过 $Q$，可以查询该数据序列和另一个数据序列的 $K$，然后对另一个数据序列进行加权利用，相当于获得了另一个数据序列的信息，以此实现了不同信息之间的相关性流动，Cross Attention 常用于各种多模态场景。

## 4. Spatialtemperal Attention

时空注意力主要有两种方式，一种是联合时空注意力，即将时间信息（不同帧的图像）和空间信息（单一帧内不同位置的图块）直接结合起来做注意力，另一种是分解式时空注意力，即在每一帧内单独做注意力，并同时在帧与帧之间做注意力。

设视频特征为

$$
X\in\mathbb{R}^{T\times S\times d},
$$

其中，$T$ 表示帧数，$S$ 表示每帧的空间 token（patch）数量，$d$ 表示特征维度。联合式时空注意力将全部 $TS$ 个 token 展平为一个序列，并一次性计算所有时空位置之间的关系，这种方法能够灵活建模任意时空位置之间的联系，表达能力较强，但计算复杂度为
$
O(T^2S^2d_k),
$
当帧数或空间 token 数较大时，计算与显存开销都很高。

分解式时空注意力把联合计算拆成空间注意力和时间注意力两个阶段。以“先空间、后时间”为例，首先在每一帧内部计算：

$$
y_{t,s}
=
\sum_{s'=1}^{S}
\alpha^{\mathrm{space}}_{t,s,s'}v_{t,s'},
$$

然后对相同空间索引的 token 沿时间维度计算：

$$
o_{t,s}
=
\sum_{t'=1}^{T}
\beta^{\mathrm{time}}_{s,t,t'}y_{t',s}.
$$

它也能间接融合不同时间和空间位置的信息，但注意力权重受到两阶段分解结构的约束，并不等价于联合式注意力。其计算复杂度为
$
O(TS^2d_k+ST^2d_k),
$
通常显著低于联合式方法，尽管这种方法损失了理论上的联合注意力的上限，但在显存预算有限的应用场景中有重要意义。

## 5. 多模态信息下，时空注意力怎么设计？

此时问题变得比较复杂，多模态信息，比如RGB相机，深度相机，激光雷达等信息等，每种信息可能有时空数据，也可能没有时空数据，如何合理处理这种相关性呢？如果全部联合，计算复杂度很高，因此，我们认为，此时关键的做法是人为对相关性进行简化和归纳，通过人工先验，手动判断哪些信息的相关性作用较大，为此设计专门的注意力机制交互方式。比较严格的说，即人工设计一个不同特征之间交互图，并让模型学习交互图中每条边的权重。

当然，在自动驾驶领域，也有一种方法是将多模态数据作为条件，注入到生成模型中，此时多模态信息成为了生成模型需要遵守的条件，然而，在作为条件注入之前，往往也会使用到一个特征融合曾，此时更常用的就是 Cross Attention 了，而不必使用时空注意力设计。
