## 1. 什么是视频生成的一致性？

"一致性"在视频生成中常被笼统使用，实际上至少指三件不同的事：

- **时间一致性**：相邻帧之间的结构与运动是否连贯，不一致则表现为闪烁、形变、运动不连续。
- **跨视角一致性**：同一时刻由多个相机（或多个视角）生成的内容是否互相自洽，失效表现为同一物体在相邻相机中位置、外观不一致。
- **重访一致性（revisit consistency）**：相机离开某区域一段时间后重新回到该区域时，生成内容是否与先前一致。失效表现为同一建筑、路面、招牌在两次观测中被生成成不同形态。

本文重点讨论第三者。重访一致性的失效可以进一步分成两种机制：**遗忘（forgetting）**，即早期内容随生成模型的限制而逐渐丢失；**漂移（drifting）**，即自回归过程中误差逐步累积放大。同时，两种机制是相互耦合的，例如，为了防止遗忘，可以增大上下文窗口（生成中用于参考的帧窗口），但这会导致模型对历史误差更敏感，加剧漂移。这种现象的根本原因是：主流视频扩散模型在有限长度的局部上下文内工作，注意力的计算复杂度随上下文长度平方增长，因此模型无法把任意长的历史信息保留在模型可调用的范围内。

## 2. 现有技术路线

### 2.1 存储历史帧，并进行检索

顾名思义，这种做法将模型生成的历史帧图像直接或间接进行存储，当模型生成下一帧时，根据相关性判定条件，检索历史帧中的相关帧，并进行条件注入。例如，Context-as-Memory（SIGGRAPH Asia 2025）直接以帧格式存储生成过的上下文，检索时使用 FOV 交并比判断相机相关性，若超过阈值，则提取该历史帧，直接使用 Concatenation 进行拼接。又例如 WorldMem（NeurIPS 2025）设计了一个 memory bank 存储记忆帧与状态，包括相机的位姿和帧的时间戳，用 memory attention 按状态检索最相关的，用于后续帧生成。VMem（ICCV 2025 highlight）用 surfel 在生成中持续维护一个粗糙几何模型，每个 surfel 记录观测过它的历史相机视角索引；生成新视角时取该视角可见的 surfel，用其索引投票决定用哪些历史帧作条件。

这三种做法都有一个共同的基础：共视性（co-visibility），即当新相机视角观测到了旧相机视角内已经存在的物体或结构时，可以直接参考其结构进行条件注入。这类方法的问题是：存储历史帧随着生成帧数的增长而线性增长，且冗余很高（例如，同一个建筑物会在几百帧内被重复记录，但却没有提供更多的信息），且检索过程和生成过程是分离的，相关性由人工设计算法进行计算，缺乏对单帧内信息的正确稳定识别。

### 2.2 显式三维记忆

近年来，为缓解长视频生成过程中因上下文窗口受限导致的场景遗忘问题，一类研究开始引入显式三维记忆（explicit 3D memory），即将历史观测或生成结果显式映射到带有空间坐标的三维表示，并在后续生成过程中根据目标相机位姿进行投影或渲染，从而维持跨时间、跨视角的空间一致性。代表性工作 Video World Models with Long-term Spatial Memory 构建长期空间 point-map，将历史场景的几何和外观信息存储于三维空间，并在相机重新访问已有区域时提供长期空间约束，从而缓解视频世界模型的遗忘问题。GEN3C 则通过单目深度估计将输入图像或历史生成帧反投影为点云形式的 3D cache，再依据新的相机轨迹将其重新渲染至二维图像平面，作为视频生成模型的条件，使模型无需完全依靠神经网络隐式记忆历史场景，同时提高相机控制精度和跨视角一致性。在自动驾驶场景中，InfiniCube 设计了 voxel world 作为持续存在的三维世界表示，并根据它提取多种二维引导信号辅助长时驾驶视频生成，此外，MagicDrive3D 利用高斯泼溅技术，支持街景的任意视角渲染。

总体而言，这类方法的优势在于：直接显式存储三维记忆可以保证三维空间信息相对完整，空间位置明确、相机视角变换可通过几何投影直接处理、长期重访一致性较强；但其通常需要深度估计、点云、voxel或3DGS等中间三维表示，增加了技术难度，且三维记忆的精度受到上述方法的限制，如果三维重建精度本身就不高，很可能影响视频生成的效果。同时，在包含大量动态目标的真实场景中，还需要解决三维记忆随时间更新以及静态结构与动态目标之间的协调问题。

### 2.3 隐式记忆

隐式记忆指的是将三维结构通过 latent，KV cache，或者其他编码方式进行压缩，供视频模型进行读取的方法。这种方法不需要完全存储三维数据，相比于显式三维记忆极大的优化了内存的占用，也是近年来比较热门的方法。例如，StateSpaceDiffuser 利用状态空间模型持续压缩完整交互历史，并将得到的长期状态特征注入扩散生成模型，使有限上下文窗口之外的信息仍能够影响后续场景生成。 ReMind 利用视频 Transformer 本身的 KV cache 作为动态记忆，通过针对遮挡、相机转向和长时间间隔设计的训练策略，使模型能够在目标暂时离开视野后继续维持并更新其隐藏状态，在重新观察时恢复符合时间演化的场景。 RECAP-Forcing 从长期生成中的内容选择问题出发，根据新出现或解除遮挡的视觉内容选择性保留相应 KV cache。

总体而言，隐式记忆具有存储开销较低、易于与现有视频 Transformer 或扩散模型结合等优势，但其内部状态通常缺乏明确的物理含义，模型究竟保存了哪些与场景结构和运动相关的信息，以及这些记忆在目标离开视野后应如何持续演化，仍缺乏统一而可解释的表示机制。

## 3. 该怎么描述“记忆”？

第 2 节按存储内容进行分类，设计时判断什么信息对视频生成有用，据此进行设计与改进，是非常符合直觉的做法。这里我们再从几个维度去评价：

### 3.1 记忆容量

- 定长压缩状态（状态空间模型、定长 memory token）：容量 \(O(1)\)，与已经生成了多少帧无关，新信息全部进行压缩，压缩到固定长度的 token 内部。
- 多帧存储：容量 \(O(T)\)，随时间线性增长，冗余极大，但是能够完整保留所有历史帧的二维信息，如果不采用 latent 压缩，还能够较完整的保存历史信息。
- 几何存储（surfel、点云、体素）：容量 \(O(A)\)，随探索过的空间增长，能够完整保留所有历史帧的三维信息。

### 3.2 记忆写入策略

写入策略要回答一个根本性的问题，什么内容值得记忆？是否在生成中每次遇到新的结构都要写入记忆？当前，绝大多数方法要么每帧无差别写入，要么按固定频率采样，相对来说，写入策略比较呆板。GIM-World 的确考虑了"记忆应当存储什么信息"，但其没有正面解决它。因此，当前研究在“如何写入这一领域仍有较大的 gap”。值得注意的是，在自然语言领域，这一问题已经开始被系统讨论：一类工作把记忆压缩形式化为给定比特预算下最小化任务失真问题，另一类工作用预测误差（惊奇度）门控记忆写入，对高惊奇度的信息直接写入，对低惊奇度内容则先进行压缩再存储、内存满时优先丢弃低惊奇度内容。但这些方法的取舍粒度都是帧级或 token 级。本文认为，对于生成式世界模型而言，真正需要回答的是所生成的场景空间中记忆预算的分配问题：即同一个场景中，什么东西值得去记忆，什么东西可以部分记忆，什么东西可以直接由生成模型所学习到的先验进行不全？这是当前研究存在的主要缺口。

## 4. 现有路线的共同局限

综合以上分析，现有方法具有一下问题：

**写入策略单一**：无论存帧、存点云还是存潜特征，"存什么"基本由存储形式本身决定，而非由内容的价值决定。其直接后果是记忆中充斥着生成先验本就能够补全的冗余内容，例如沥青路面、天空、常规建筑立面等，与它们对一致性的实际贡献严重不匹配。

**静态与动态未被区分对待**：显式三维记忆本质上假设被记忆的内容是静止的，因此在包含大量动态目标的真实场景中面临记忆更新的困难；现有做法多依赖实例级标注（如轨迹 ID）来拆分前景与背景。缺乏无监督的静动分解，就无法回答"什么应当被记住、什么应当被遗忘"。

**revisit 的相机视角差异有限**： 现有评测多在自由移动或小幅绕行下进行，revisit 时的视角与初次观测时的视角差异有限。当读取方向相对写入方向发生大幅反转时，例如自动驾驶内的车辆掉头等场景，外观特征的可匹配性可能会受到较大影响。

上述问题首先需要解决的是写入策略的问题，或许，前两个问题本身就是一个问题，只是现有方法没有构建出一个包含两种结构的策略。
