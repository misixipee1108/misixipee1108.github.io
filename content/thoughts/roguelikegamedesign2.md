## 一、黑流树海肉鸽的基本建模

在上一篇文章中，我们将肉鸽游戏的一局流程描述为：游戏系统从某个初始状态出发，在随机生成、游戏规则与玩家连续决策的共同作用下，不断改变当前状态及其未来可达状态空间。为了进一步分析《明日方舟》集成战略“沉沦者的黑流树海”，本章首先将该框架中的抽象变量与游戏内的具体系统一一对应。

> 本文对具体机制的描述以截至2026年8月的游戏版本为基础。

在一局游戏开始前，玩家需要确定难度、探索分队和初始招募等条件，局外成长系统“生命游戏”的解锁情况也会改变单局游戏内节点生成，难度等因素，为了方便分析，我们统一按照 N15 难度下，“生命游戏”完全解锁的状态进行分析，同时不考虑任何襁褓的局外继承。

### 1 理论概念与游戏机制的总对应

| 前文理论概念   |                   符号 | 《黑流树海》中的对应对象                      | 在模型中的作用                  |
| -------- | -------------------: | --------------------------------- | ------------------------ |
| 外部条件     |             (\theta) | 难度、探索分队、局外解锁状态、当前版本内容池            | 决定一局游戏的初始条件和规则环境         |
| 游戏状态     |                (s_t) | 当前层数、地图、所在节点、行动力、队伍、收藏品、零件、追猎状态等  | 描述时刻 (t) 游戏中所有与后续结果有关的变量 |
| 玩家状态     |              (s_t^P) | 目标生命值、护盾、部署位、携带位、指挥等级等               | 决定玩家的生存能力和容错空间           |
| 构筑状态     |              (s_t^B) | 已招募干员、进阶状态、收藏品、分队效果、临时强化          | 决定玩家能够处理哪些遭遇，以及后续奖励的价值   |
| 资源状态     |              (s_t^R) | 行动力、希望、源石锭、招募券、零件和零件使用次数       | 限制玩家可执行的行为，并影响未来可达空间     |
| 世界状态     |              (s_t^W) | 网格地图、节点类型、道路、当前位置、出口、曲折密道、节点标记等   | 描述当前地图结构及其动态变化           |
| 遭遇状态     |              (s_t^E) | 战斗、事件、商店、应急助力名单及其内部状态             | 描述一次具体交互中的短期状态           |
| 状态空间     |                  (S) | 所有符合游戏规则的地图、资源、构筑和遭遇组合            | 描述系统理论上允许存在的状态集合         |
| 客观可达状态空间 |           (S_R(s_t)) | 从当前状态出发，通过合法行动和随机结果能够到达的状态        | 描述当前局面真正保留下来的可能性         |
| 玩家有效状态空间 |            (S_R^\pi) | 某类玩家凭借自身知识、目标和习惯实际会反复进入的状态        | 描述玩家真正体验到的系统范围           |
| 观测       |                (o_t) | 已揭示节点、当前行动力、已知出口、道具效果等            | 描述玩家在时刻 (t) 能够看到的信息      |
| 玩家知识     |              (z_t^K) | 对地图生成规律、节点分布、关卡池和追猎规则的了解          | 影响玩家如何解释未知信息并选择行动        |
| 行动       |                (a_t) | 移动、使用加工品移动、使用招募券、选择出口等         | 由玩家主动执行，并改变后续状态          |
| 状态转移     | (P(s' \mid s_t,a_t)) | 移动后的资源变化、节点揭示、战斗结果、奖励和追猎触发        | 描述行动和随机结果如何产生下一状态        |
| 机制耦合     |               (\Phi) | 行动力与地图、加工品与移动、出口与存券、追猎与后续行动力之间的关系 | 描述一个变量如何改变另一个系统的价值或规则    |
| 状态空间裁剪   |         (\mathcal C) | 消耗行动力、完成节点、使用零件、选择出口、进入追猎等        | 描述哪些未来路径被关闭，以及关闭的原因      |

给定外部条件 $\theta$ 后，一局游戏可以抽象为：

$$
s_0=s_0(\theta),
$$

并通过连续的观测、行动和状态转移推进：

$$
s_t
\xrightarrow{O}
o_t
\xrightarrow{\pi(\cdot\mid o_t,z_t)}
a_t
\xrightarrow{P(\cdot\mid s_t,a_t)}
s_{t+1}.
$$

黑流树海相比于以往的集成战略肉鸽，最大的不同是采用了网格状二维地图，根据玩家社群的统计，系统在每一层有若干个地图生成模板，地图生成后，系统已经确定模板上某些节点的位置和连接情况。玩家在游戏中只能看到一部分节点信息。进一步的，即使玩家可以看到部分节点的信息，玩家也并非随时随地可以到达这些节点，因此，为了后续分析方便，我们需要区分：

$$
\text{地图中存在}
\neq
\text{玩家已经看见}
\neq
\text{当前状态下可到达}
$$

最后，前文的三层复杂度，在本作中可以分别对应如下问题：

| 复杂度层次   | 在黑流树海中的具体问题                                |
| ------- | ------------------------------------------ |
| 系统复杂度   | 网格地图移动、收藏品、招募干员、特殊选择等因素之间能够形成多少种不同的状态空间 |
| 局部决策复杂度 | 玩家在当前节点如何进行作战、向哪里移动、是否使用加工品等    |
| 长程策略复杂度 | 玩家如何规划整层路线、分配行动力、安排存券使用，承担追猎带来的影响，完成目标结局       |

## 二、网格地图设计的意义与取舍

我们首先给一个确切的结论：网格地图把传统有向图地图的肉鸽中的路线选择，转化为由位置、信息、行动力和未来目标共同决定的连续决策过程，这种设计大大增加了玩家的局部决策复杂度，但同时也对玩家的信息处理能力提出了更高的要求。当前版本中，网格地图下移动方式较为多样，的确起到了相当不错的增加局部决策复杂度的效果。
